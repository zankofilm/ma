# کلاینت Native Android جوانرود — فاز ۱ فعال‌سازی

نسخه کلاینت قبلی مبتنی بر Python/Kivy کنار گذاشته شده است. این پروژه از صفر
با Kotlin و Jetpack Compose نوشته شده و هنگام اجرا هیچ وابستگی به Python،
Kivy، Buildozer، Chrome یا WebView ندارد.

## امکانات همین فاز

- اجرای مستقیم و مستقل APK روی Android 8 به بالا
- رابط فارسی و راست‌به‌چپ
- ایجاد شناسه و کلید اختصاصی دستگاه
- حفاظت کلیدها با Android Keystore
- ساخت فایل درخواست فعال‌سازی `.jrr`
- انتخاب و نصب فایل فعال‌سازی یا تمدید `.jra`
- سازگاری رمزنگاری و امضا با فرمت فعلی نسخه ادمین Python
- ذخیره رمزنگاری‌شده مجوز در فضای خصوصی برنامه
- کنترل تاریخ شروع، انقضا، مسدودی و عقب‌رفتن ساعت دستگاه
- نمایش خطای راه‌اندازی داخل خود برنامه به‌جای بسته‌شدن بی‌پیام
- ذخیره گزارش آخرین کرش و نمایش آن در اجرای بعدی

## روش ساخت APK در GitHub

1. همه محتویات ZIP را در ریشه یک مخزن GitHub آپلود کنید.
2. وارد تب `Actions` شوید.
3. Workflow با نام `Build Javanrood Native Android Phase 1` را اجرا کنید.
4. پس از موفقیت، Artifact زیر را دانلود کنید:

`javanrood-native-phase1-apk`

APK داخل Artifact:

`app-debug.apk`

## نکته امنیتی

Keystore موجود فقط برای نسخه توسعه و تست میدانی است تا APKهای بعدی با همان
امضا روی نسخه قبلی نصب شوند. پیش از انتشار عمومی باید Keystore نهایی سازمان
جایگزین شود.

## ادامه پروژه

تا زمانی که این چهار مورد روی گوشی تأیید نشوند، مرحله ورود اضافه نمی‌شود:

1. برنامه بدون کرش باز شود.
2. فایل `.jrr` ساخته و ذخیره شود.
3. نسخه ادمین فایل درخواست را قبول کند.
4. فایل `.jra` روی همان گوشی نصب و اطلاعات مجوز نمایش داده شود.
