# امنیت فاز ۱

- Backup و انتقال داده برنامه غیرفعال است.
- کلید AES داخل Android Keystore تولید و غیرقابل استخراج است.
- seed کلید Ed25519 و مجوز فقط به‌صورت AES-GCM ذخیره می‌شوند.
- مجوز به device ID و public key همان نصب متصل است.
- اولین فایل مدیر با روش Trust On First Use ثبت می‌شود.
- تمدید فقط با همان کلید امضای مدیر پذیرفته می‌شود.
- keystore موجود در پوشه `keystore/` فقط کلید امضای APK توسعه است تا
  همه buildهای GitHub قابل به‌روزرسانی روی همان نصب باشند. پیش از انتشار
  نهایی باید با کلید خصوصی تولید جایگزین شود.
