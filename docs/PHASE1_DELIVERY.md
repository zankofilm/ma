# تحویل فاز ۱

## محدوده

این تحویل فقط شامل فعال‌سازی است. صفحه ورود، نقشه، فرم‌ها و تبادل اطلاعات
عمداً وارد پروژه نشده‌اند.

## زنجیره فعال‌سازی

1. برنامه یک seed امضای Ed25519 و seed هویت دستگاه ایجاد می‌کند.
2. هر دو در فایل رمزنگاری‌شده با کلید AES-256 متعلق به Android Keystore ذخیره می‌شوند.
3. با کد ملی مسئول، فایل `.jrr` امضاشده ساخته می‌شود.
4. مدیر از همان درخواست، فایل `.jra` وابسته به device_id و public key صادر می‌کند.
5. برنامه امضای Ed25519 مدیر را کنترل می‌کند.
6. محتوا با Scrypt و AES-GCM و کد ملی رمزگشایی می‌شود.
7. device_id و client_sign_public با همین نصب تطبیق داده می‌شوند.
8. مجوز در فضای خصوصی و رمزنگاری‌شده ذخیره می‌شود.

## استقلال اجرایی

در APK هیچ Python، Kivy، SDL یا WebView وجود ندارد. فایل‌انتخاب‌کن نمایش‌داده‌شده
برای ذخیره یا انتخاب `.jrr/.jra`، File Picker استاندارد خود Android است.
