# آیکون برنامه

طراحی: سپر سرمه‌ای با حاشیه‌ی طلایی (نماد امنیت و مجوز دستگاه) و سه
نماد انسانی سفید/طلایی در مرکز (نماد کمیته‌ی محلی/جامعه)، هم‌راستا با
پالت رسمی برنامه (`theme_kv.py`).

## فایل‌ها

- `javanrood_app.png` — آیکون اصلی ۵۱۲×۵۱۲ که `buildozer.spec`
  (`icon.filename`) از آن برای آیکون پیش‌فرض استفاده می‌کند.
- `android_res/mipmap-*/ic_launcher.png` و `ic_launcher_round.png` —
  ست کامل legacy برای اندروید ۷ و پایین‌تر، در همه‌ی دانسیته‌ها
  (mdpi تا xxxhdpi).
- `android_res/drawable/ic_launcher_foreground.png` و
  `ic_launcher_background.png` + `android_res/mipmap-anydpi-v26/*.xml` —
  آیکون آداپتیو برای اندروید ۸ به بعد؛ سیستم خودش شکل (مربع گردگوشه،
  دایره، قطره و...) را بر اساس لانچر گوشی می‌زند.

این پوشه از طریق `android.add_resources` در `buildozer.spec` مستقیماً
به `res/` پروژه‌ی گریدل اضافه می‌شود، بدون نیاز به تنظیم دستی اضافه.

## بازتولید یا تغییر طراحی

آیکون به‌صورت برداری (نه دستی در فتوشاپ) با یک اسکریپت Pillow ساخته
شده تا در هر سایزی (از ۴۸px موبایل تا ۲۰۴۸px) لبه‌ها تیز بمانند. برای
تغییر رنگ یا طرح، پارامترهای پالت (`NAVY_DARK`, `GOLD`, ...) در ابتدای
اسکریپت طراحی قابل تنظیم‌اند.
