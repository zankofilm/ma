# فونت فارسی برای نمایش صحیح در اپلیکیشن اندروید

بر خلاف نسخه دسکتاپ (که به فونت‌های نصب‌شده در ویندوز/مک تکیه می‌کند)،
نسخه اندروید باید فونت فارسی را **همراه خود** حمل کند، چون گوشی‌های
اندرویدی معمولاً فونت فارسی باکیفیت از قبل نصب ندارند و Kivy هم به
فونت‌های سیستمی دسترسی مطمئنی روی اندروید ندارد.

## مراحل

۱. از صفحه ریلیزهای رسمی فونت وزیرمتن دانلود کنید:
   https://github.com/rastikerdar/vazirmatn/releases

۲. از داخل فایل zip، این دو فایل را پیدا کنید (داخل پوشه‌ای مثل `fonts/ttf/`):
   - `Vazirmatn-Regular.ttf`
   - `Vazirmatn-Bold.ttf`

۳. آن‌ها را دقیقاً با همین نام‌ها در همین پوشه (`assets/fonts/`) قرار دهید.

۴. `buildozer.spec` از قبل تنظیم شده تا این پوشه را در APK بسته‌بندی کند
   (`source.include_patterns = ../assets/*,../assets/fonts/*`).

اگر این فایل‌ها موجود نباشند، برنامه همچنان اجرا می‌شود اما با فونت
پیش‌فرض Kivy (که از حروف فارسی چسبان پشتیبانی نمی‌کند) نمایش داده
خواهد شد.
